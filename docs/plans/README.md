# Feature plans

One file per feature, named after it (e.g. `fermenter-cell-bond-graph.md`). A feature plan is the
low-level working plan for implementing one piece of [`adapting_plan.md`](../../adapting_plan.md):
steps, files, tests. It never overwrites `adapting_plan.md`; when a feature changes the high-level plan,
update the relevant section there. Delete or archive a feature plan once the feature is done.
